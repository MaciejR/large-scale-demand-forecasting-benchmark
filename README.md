# Demand Forecasting Review & Benchmark (2026)

Academic project focused on **short-term demand forecasting at scale** (thousands of SKUs).

## Scope
- Short-term horizons (7–28 days)
- Large-scale retail / supply chain datasets
- Statistical, ML, Deep Learning, Transformer, and Foundation models
- Accuracy *and* computational cost

## Components
- `paper/` – academic paper materials (outline, positioning)
- `benchmark/` – experimental protocol and benchmark design
- `references/` – curated bibliography

The goal is a **reproducible, publishable benchmark** suitable for IJF / EJOR / ESWA / applied ML venues.
