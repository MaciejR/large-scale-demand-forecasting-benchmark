# IJF Submission Checklist

Checked against the International Journal of Forecasting Guide for Authors on
2026-08-20.

## Files

- [x] Public manuscript source and PDF.
- [x] Double-anonymized manuscript source with author, affiliation,
  acknowledgements, and identifying repository links removed.
- [x] Separate title-page source.
- [x] Cover letter disclosing the historical Zenodo technical report and the
  differences from the submitted article.
- [x] Four concise highlights.
- [x] Elsevier declaration-of-interests DOCX generated from the official
  template and structurally verified; final visual inspection remains part of
  the Editorial Manager upload review.
- [x] Anonymized replication supplement build is gated by required-file,
  checksum, privacy, archive-content, and source-state audits.

## Manuscript requirements

- [x] Corresponding-author e-mail is present on the title page.
- [ ] Complete corresponding-author postal address supplied privately.
- [x] Abstract contains 132 words, within the required 100--150 words.
- [x] At least five keywords are present.
- [x] Competing-interest statement is present.
- [x] Generative-AI use in manuscript preparation is declared.
- [x] Figures and tables are embedded with captions and cited in the text.
- [x] References and manuscript build are covered by the release audits.
- [x] No human participants or animals are involved.
- [x] No external funding is reported.

## Double-anonymized review

- [x] Author name, e-mail, affiliation, CRediT statement, and acknowledgements
  are absent from the anonymous manuscript.
- [x] Identifying GitHub and Zenodo links are replaced by an anonymous data
  availability statement.
- [x] PDF metadata and extracted text pass the final anonymity audit.
- [x] Anonymous replication supplement privacy audit rejects author identity,
  private paths, cache state, secrets, symlinks, and identifying binary
  metadata.

## Editorial Manager

- [ ] Author confirms the work is not under consideration elsewhere.
- [ ] Author confirms the no-competing-interest declaration.
- [ ] Author confirms the no-external-funding statement.
- [ ] Author provides or approves 4--6 suggested reviewers and confirms no
  conflicts of interest.
- [ ] Author chooses subscription publication or open access if prompted.
- [ ] Author signs in to Editorial Manager and reviews the generated submission
  PDF.
- [ ] Final submit action is explicitly confirmed.
- [ ] Manuscript ID, submitted timestamp, and submitted commit are recorded in
  `docs/IJF_SUBMISSION_LOG.md`.
