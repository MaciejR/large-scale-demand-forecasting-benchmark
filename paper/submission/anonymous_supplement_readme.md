# Anonymized Replication Supplement

This supplement accompanies a double-anonymized journal submission on
foundation models for retail demand forecasting. It contains derived analysis
tables, selected experiment and analysis code, and focused validation
instructions for the packaged scientific artifacts.

Raw competition datasets, model checkpoints, MLflow stores, logs, local caches,
full untracked prediction trees, repository metadata, author-identifying files,
and private machine metadata are excluded. Dataset access instructions refer to
the original public providers.

The archive deliberately withholds the searchable commit identifier and records
that fact in `SOURCE_STATE.txt`; file hashes are in `CHECKSUMS.txt`. Author and
repository details will be restored after the double-anonymized review process.
