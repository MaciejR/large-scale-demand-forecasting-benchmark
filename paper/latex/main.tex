\begin{abstract}
We present a PRISMA-informed review and exploratory cross-benchmark
reanalysis of foundation models for short-term retail demand forecasting.
The primary quantitative file contains $k=498$ Source~A comparisons from
two benchmark suites, fev-bench and GIFT-Eval.  This repair uses
$\log(\text{FM metric}/\text{best conventional baseline metric})$ as the
main contrast and treats the recorded series-count term
$1/n_{\text{FM}}+1/n_{\text{baseline}}$ only as a weighting proxy, not as a
validated sampling variance.  Results are therefore reported as
suite- and metric-specific benchmark summaries rather than as a
confirmatory pooled meta-analysis.  SQL shows the strongest directional FM
advantage (median log-ratio $-0.229$, FM better in 92\% of rows), while
\WAPE{}/ND (median $-0.047$, 66\%) and \MASE{} (median $-0.036$, 61\%)
are much closer to the best baseline.  GIFT-Eval is uniformly favourable
to FMs in this extraction, whereas fev-bench is more heterogeneous.
To address the strongest variance critique for a concrete Source~A slice, we
rerun official fev-bench retail windows for Seasonal Naive,
Chronos-Bolt-Tiny, Chronos-2, TiRex, and TimesFM~2.5, store prediction-level outputs, and compute
paired bootstrap \WAPE{} log-ratio covariance matrices for 20 retail tasks
and 179,258 paired series-window units for each FM contrast.
The current matched-panel Source~B repair covers M5, Rohlik, and
Favorita: 100 shared top-volume series per dataset, common rolling-origin
windows, prediction-level outputs, run ledgers, and paired bootstrap
contrasts with an empirical log-ratio covariance matrix for Seasonal Naive,
recursive/direct LightGBM, Chronos-Bolt-Tiny, Chronos-2, Moirai~2.0-Small,
batched TiRex, and TimesFM~2.5 on all three datasets.
In this repaired subset Chronos-2 is lower than
the best local baseline in all nine dataset--horizon cells; Moirai is lower
in all nine point estimates; TiRex is lower in all nine point estimates
with bootstrap intervals excluding zero in seven; Chronos-Bolt is
approximately tied on M5 and worse on Rohlik and Favorita; and TimesFM~2.5 is
lower on M5 and Rohlik but near parity on Favorita.  The defensible conclusion
is conditional: observed rankings depend on metric, baseline choice,
protocol, workload matching, and demand characteristics.  We provide a
validation checklist and cost-error diagnostics instead of deterministic
deployment rules.
\end{abstract}

\section*{Data availability}
A historical technical-report snapshot is archived on Zenodo at
\url{https://doi.org/10.5281/zenodo.21338004}.  The live repository for the
repaired analysis is
\url{https://github.com/MaciejR/large-scale-demand-forecasting-benchmark};
the release package corresponding to this manuscript is prepared as a v1.12
Zenodo-ready archive under \path{release/} rather than overwriting the
historical snapshot.  The package records the source commit in
\path{COMMIT.txt} and file hashes in \path{CHECKSUMS.txt}.
The repository includes derived extraction tables, analysis code, generated
tables/figures, study-characteristics data, audit outputs, and replication
scripts, but not raw competition data or untracked fev-bench prediction
parquet trees.
The M5 dataset is publicly available via Kaggle; the Favorita
dataset is publicly available via Kaggle; the Rohlik~v2 dataset
is available at \url{https://github.com/Rohlik/rohlik-orders-forecasting-challenge}.
